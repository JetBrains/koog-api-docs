ContentMessagePartsBuilder

open class ContentMessagePartsBuilder : ContentPartsBuilderBase<List<MessagePart.ContentPart>> (source)

A builder for constructing parts for prompt messages. All parts are added to a list in declaration order and can be retrieved through the build method.

Example usage:

val parts = ContentMessagePartBuilder().apply {
    text("Hello! Here's an image:")
    image("screenshot.png")
    + "And here's a file:"
    binaryFile("report.pdf")
}.build()
