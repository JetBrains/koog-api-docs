MockExecutorDSLBuilder

class MockExecutorDSLBuilder(clock: KoogClock, serializer: JSONSerializer, tokenizer: Tokenizer? = null)(source)

Builder class for creating mock LLM executors for testing.

This class provides a fluent API for configuring mock responses for LLM requests and tool calls. It allows you to define how the LLM should respond to different inputs and how tools should behave when called during testing.

Parameters

clock

A clock that is used for mock message timestamps

serializer

Serializer used to serialize and deserialize tool arguments and results

tokenizer

Optional tokenizer that will be used to estimate token counts in mock messages

See also

getMockExecutor

Prefer it for creating and configuring mock LLM executors.
